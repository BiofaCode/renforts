## Description (à coller dans « Description »)

**Renforts** est un petit jeu d'armée en 3D, jouable directement dans le navigateur, sur ordinateur comme sur téléphone.

Ton armée avance toute seule. À toi de choisir les bonnes portes :

- **+** et **×** font grossir ton armée
- **−** et **÷** la font fondre

Écrase les escouades rouges, ramasse les caisses de renfort, évite les barricades et les champs de mines, puis affronte l'armée qui garde le fort. Chaque soldat qui entre dans le fort rapporte des médailles.

**Au camp**, dépense tes médailles :

- **Recrues** : plus de soldats au départ
- **Entraînement** : tes soldats éliminent plus d'ennemis
- **Butin** : une plus grosse prime du fort

Un **Général** géant t'attend toutes les 5 opérations, et le décor change toutes les 3 : plaine, désert, neige.

### Commandes

- **Téléphone** : glisse le doigt à gauche ou à droite
- **Ordinateur** : souris, flèches ou Q / D · Échap ou P pour la pause

Ta progression est sauvegardée dans ton navigateur.
